## About

This project implements a data extraction and transformation pipeline using the HAPI FHIR Public Test Server.

The pipeline retrieves FHIR resources through the REST API, processes each resource independently, and generates clean JSON files containing only the fields required for analysis.

### Design Decision

Instead of introducing a relational database as an intermediate storage layer, this project stores the transformed data as clean JSON files.

Since the final consumer of the data is **Power BI**, using JSON files simplifies the overall architecture while still providing a structured and reusable data source. Power BI is responsible for the final modeling tasks, such as renaming columns, removing unnecessary fields, defining relationships, and creating analytical measures.

This design offers several advantages:

- Reduces the complexity of the data pipeline.
- Eliminates the need to maintain an intermediate database.
- Decreases development and deployment time.
- Keeps the ETL process focused on extraction and transformation.
- Takes advantage of Power BI's built-in data transformation capabilities.

**Note:** This repository focuses exclusively on the ETL process (Extract, Transform, Load). The generated JSON files are intended to be consumed by Power BI or any other analytics platform.

## Project Structure

- **database/**
  - Stores the cleaned JSON files generated by the pipeline.
  - Can later be replaced with a relational database if required.

- **extract/**
  - Contains the extraction logic for each FHIR resource.
  - Each resource is processed independently.

- **parser/**
  - Includes optional parsing and data normalization utilities.

- **functions**
  - Shared helper functions used throughout the project.

- **test**
  -Software Testing if the project scale.

## Features

- Extracts data from the HAPI FHIR Public Test Server.
- Processes multiple FHIR resources independently.
- Generates lightweight JSON files for analytics.
- Modular architecture that simplifies adding new resource types.
- Ready to be consumed by Power BI or other BI tools.
